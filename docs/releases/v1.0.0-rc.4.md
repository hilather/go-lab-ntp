## Highlights

A reset that moves management HTTP, or turns it off, closes the old
listener at once and drains the old server in the background for up to
5 s. A drain timeout is not a failed rebind. Turning management off
leaves the listen address empty. While management auth is attached,
reset does not install a bootstrap whose bearer secret file cannot be
read or whose bearer list is empty. A failed management rebind, after
the NTP listener already moved, rolls that listener back and leaves the
active snapshot unchanged.
`labntp mcp-stdio` re-resolves the startup token on each tool call.
Duration formatting no longer crashes on the minimum signed duration.
View durations that `time.ParseDuration` cannot represent are rejected.

Management HTTP `bodyLimit`, `requestsPerSecond`, `burst`, and
`maxConcurrent` take effect on apply and on reset. A lowered
`bodyLimit` applies live to REST and `/mcp`. `/mcp` cannot exceed the
body limit it started with until restart. Raising `requestsPerSecond`,
`burst`, or `maxConcurrent` applies live to REST; `/mcp` keeps its
startup ceiling until restart. An explicit `bodyLimit: 0` means the
startup default (1 MiB), and an explicit `maxConcurrent: 0` means the
startup default (256). REST mutation JSON rejects unknown fields. NTP
per-IP and limited buckets, and the MCP management per-remote buckets,
evict idle keys and stay capped.

Go toolchain is go1.26.9 (GO-2026-6603..6617). `golang.org/x/sys` is
v0.47.0 (GO-2026-5024). Web development dependencies `source-map-js`
1.2.2 and `undici` 8.10.2 are lockfile only; the built web assets are
byte-identical.

The tag release gate accepts only the green push for that tag and SHA.
Each required CI job name must appear exactly once with conclusion
success. A manual re-gate checks the tag before checkout, peels it, and
retries only exit 75. A tag push and a manual re-gate of the same tag
share one release concurrency group. Release checkout does not persist
credentials. The image build context excludes `.git`, `.github`,
`docs`, and every `testdata` directory.
