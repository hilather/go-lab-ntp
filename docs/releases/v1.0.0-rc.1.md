## Highlights

LabNTP is a laboratory NTPv3/v4 unicast server with **per-IP virtual clocks**. SUTs speak NTP; LabNTP answers from a compiled view so one tester can skew Kerberos, jump a cert window, or drift TOTP **without** moving the lab host clock.

## Residual

- `make web-*` exits 1 until the SPA lands.
- Host-publish per-IP isolation needs source-preserving UDP (`userland-proxy: false` or macvlan). Compose-network and `GET /v1/views/preview` stay reliable without that.
- Default `make test-container` uses `--ntp-listen=:1123` + `cap_drop: ALL`. Gated `LABNTP_TEST_NET_BIND=1` proves `:123` + `NET_BIND_SERVICE`.
