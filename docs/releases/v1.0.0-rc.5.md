# LabNTP 1.0.0-rc.5 Release Notes

Release date: 2026-10-26
Previous release: 1.0.0-rc.4
Application version: 1.0.0-rc.5

## Highlights

Toolchain-only release after 1.0.0-rc.4 ([#15](https://github.com/hilather/go-lab-ntp/pull/15)). Go toolchain 1.26.9 → 1.26.10. Go 1.26.9 lacks the crypto/x509 fix for GO-2026-6809. No behavior, API, MCP or configuration change.

## Added

- None.

## Changed

- Go toolchain pinned to go1.26.10: `go.mod` `toolchain`, CI `GO_VERSION` in `ci.yml` and `release.yml`, Dockerfile `golang:1.26.10-alpine`, design decision D18, remaining-work release env.

## Residual

- Residuals from 1.0.0-rc.4 are unchanged. See [v1.0.0-rc.4](v1.0.0-rc.4.md) and [docs/remaining-work.md](../remaining-work.md).

## Deployment and operations

- The image build stage uses `golang:1.26.10-alpine`. Do not tag until required CI on the exact SHA is green.

## CI and release evidence

- Tag-gate requires that tag's own completed push run with every required CI job green. A pull-request run or a main-branch push of the same SHA does not satisfy it.
